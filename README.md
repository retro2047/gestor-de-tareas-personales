# 📋 Gestor de Tareas Personales

Aplicación web desarrollada en **JavaScript** orientada a la gestión eficiente, organización y seguimiento de tareas diarias. 

## 🚀 Funcionalidades
- **Gestión de Tareas:** Creación, lectura, actualización y eliminación (CRUD) de tareas personales.
- **Categorización:** Organización de tareas por etiquetas o categorías.
- **Interfaz Dinámica:** Experiencia de usuario fluida y reactiva.

## 🛠️ Tecnologías utilizadas
- **Lenguaje:** JavaScript
- **Entorno y Herramientas:** Node.js, NPM
- **Bundler:** Vite
- **Linter:** ESLint

## ⚙️ Cómo ejecutar el proyecto localmente
1. Clona este repositorio: `git clone https://github.com/retro2047/gestor-de-tareas-personales.git`
2. Navega al directorio del proyecto: `cd gestor-de-tareas-personales`
3. Instala las dependencias: `npm install`
4. Inicia el servidor de desarrollo: `npm run dev` o `npm start`
